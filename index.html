Cactus
UI Library

A fast, themeable UI library for Roblox executors. Tabs, subtabs, sections, toggles, sliders, dropdowns, color pickers, keybinds, notifications — all wired up with smooth animations out of the box.

loadstring local Cactus = loadstring(game:HttpGet("https://raming6.github.io/cacuilib/Cactus.lua"))() 
Installation
Host CactusLib.lua anywhere with a raw URL (GitHub raw, your own CDN). Load it with a single line.
lua
1local Cactus = loadstring(game:HttpGet("https://raming6.github.io/cacuilib/Cactus.lua"))()
HttpGet must be enabled in your executor. The library injects its ScreenGui into CoreGui and falls back to PlayerGui if that fails.
Quick start
A minimal script that creates a window, one tab, one section, and a toggle.
lua
1local Cactus = loadstring(game:HttpGet("https://raming6.github.io/cacuilib/Cactus.lua"))()
2
3local Window = Cactus.CreateWindow({
4 Title = "My Script",
5 Subtitle = "v1.0",
6})
7
8local MainTab = Window:AddTab({ Name = "Main" })
9local Section = MainTab:AddSection({ Name = "Combat" })
10
11Section:AddToggle({
12 Name = "Aimbot",
13 Default = false,
14 Flag = "Aimbot",
15 Callback = function(enabled)
16 print("Aimbot:", enabled)
17 end
18})
Flags & Variables
Flags let you read any component's current value from anywhere in your script without holding a reference to the component object. Every component that accepts a Flag key writes to Cactus.Flags.
VariableTypeDescription
Cactus.Flags table Global key-value store updated whenever a flagged component changes. Read any flag at any time — the table is always current.
Cactus.Flags["YourFlag"] any The live value of a specific component. Type matches the component: boolean for Toggle, number for Slider, string or table for Dropdown, Color3 for ColorPicker, Enum.KeyCode for Keybind, string for TextBox.
lua — reading flags
1-- set the Flag key on any component
2Section:AddToggle({ Name = "ESP", Flag = "ESP" })
3
4-- read it anywhere
5if Cactus.Flags.ESP then
6 -- draw boxes
7end
8
9-- or use in a RunService loop
10game:GetService("RunService").Heartbeat:Connect(function()
11 local fov = Cactus.Flags.AimbotFOV
12 -- use fov directly
13end)
Tip: Flags are set immediately when a component is created (using Default) and updated on every user interaction. You don't need to wait for a callback.
CreateWindow
Creates the root UI frame. Returns a Window object. Call this once at the top of your script.
KeyTypeDefaultDescription
Titlestring"Cactus"Left-side header text. Shown in white.
Subtitlestring""Shown after the title in a muted colour. Good for version strings.
lua
1local Window = Cactus.CreateWindow({
2 Title = "Cactus",
3 Subtitle = "v2.1",
4})
Window methods
Methods on the object returned by CreateWindow.

Window:Open() void

Animates the window back in. Equivalent to pressing RightShift.

Window:Close() void

Shrinks the window to 0×0 with a spring animation. The GUI still exists — call Open to bring it back. Toggle with RightShift.

Window:Destroy() void

Permanently destroys the ScreenGui. Nothing in the window will work after this.
lua
1Window:Close() -- hide
2Window:Open() -- show
3Window:Destroy() -- nuke

4})
AddSubTab
Adds a horizontal sub-tab row inside a tab's header. Each sub-tab has its own scrollable page. Useful for splitting a tab into categories (e.g. Aimbot / Visuals / Misc).
ArgTypeDescription
namestringThe sub-tab label text.
lua
1local AimbotSub = MainTab:AddSubTab("Aimbot")
2local ESPSub = MainTab:AddSubTab("ESP")
3local Section = AimbotSub:AddSection({ Name = "Settings" })
Note: If you use AddSubTab on a tab, add sections onto the sub-tab object — not the tab directly. Mixing both on the same tab is not supported.
AddSection
Creates a named container inside a tab or sub-tab. Sections lay out side-by-side horizontally. Each one auto-expands vertically to fit its components.
KeyTypeDefaultDescription
Namestring"Section"Title shown in the section header bar.
lua
1local Left = Tab:AddSection({ Name = "Combat" })
2local Right = Tab:AddSection({ Name = "Movement" })
AddToggle
A boolean checkbox. Lights up with the accent colour when enabled.
KeyTypeDefaultDescription
Namestring"Toggle"Label text shown next to the checkbox.
DefaultbooleanfalseInitial state. Applied immediately on creation.
FlagstringnilKey name in Cactus.Flags. Stores a boolean.
CallbackfunctionnilCalled with (boolean) whenever the value changes.

Methods

MethodDescription
:Set(bool)Programmatically set the value. Fires the callback.
:Get()Returns the current boolean value.
lua
1local ESPToggle = Section:AddToggle({
2 Name = "ESP",
3 Default = false,
4 Flag = "ESP",
5 Callback = function(v) print("ESP:", v) end
6})
7
8ESPToggle:Set(true) -- force on
9print(ESPToggle:Get()) -- true
AddSlider
A draggable numeric range input. Click and drag the track to set a value.
KeyTypeDefaultDescription
Namestring"Slider"Label above the track.
Minnumber0Minimum value (inclusive).
Maxnumber100Maximum value (inclusive).
DefaultnumberMinStarting value. Clamped to [Min, Max].
Suffixstring""Appended to the value display. E.g. "%", " ms".
PrecisionnumbernilSnap interval. 0.1 snaps to one decimal place. nil rounds to integers.
FlagstringnilKey in Cactus.Flags. Stores a number.
CallbackfunctionnilCalled with (number) on every drag tick.
lua
1local FOVSlider = Section:AddSlider({
2 Name = "FOV",
3 Min = 10,
4 Max = 360,
5 Default = 90,
6 Suffix = "°",
7 Flag = "AimbotFOV",
8 Callback = function(v) print("FOV:", v) end
9})
10
11FOVSlider:Set(120) -- programmatic set
12print(FOVSlider:Get()) -- 120
AddDropdown
A collapsible option picker. Supports single-select and multi-select modes.
KeyTypeDefaultDescription
Namestring"Dropdown"Label shown above the dropdown box.
Itemstable{}Array of strings. Each becomes a selectable option.
DefaultstringnilPre-selected option. Must match an item in Items.
MultibooleanfalseAllow multiple selections. Flag stores a table of strings when true.
FlagstringnilKey in Cactus.Flags. Stores string (single) or table (multi).
CallbackfunctionnilCalled with the current value on change.

Methods

MethodDescription
:Set(value)Set the selected value programmatically.
:Get()Returns current selection.
:SetItems(table)Replace the item list. Rebuilds the dropdown in place.

1local BoneDD = Section:AddDropdown({
2 Name = "Target Bone",
3 Items = { "Head", "Neck", "Torso" },
4 Default = "Head",
5 Flag = "AimbotBone",
6 Callback = function(v) print("Bone:", v) end
7})
8
9-- multi-select example
10Section:AddDropdown({
11 Name = "ESP Teams",
12 Items = { "Enemies", "Team", "All" },
13 Multi = true,
14 Flag = "ESPTeams"
15})

AddKeybind
A key-capture input. Click the box to enter listening mode, then press any key to bind it. Fires the callback globally whenever that key is pressed.
KeyTypeDefaultDescription
Namestring"Keybind"Label text.
DefaultEnum.KeyCodeUnknownStarting key. Use Enum.KeyCode.X syntax.
FlagstringnilKey in Cactus.Flags. Stores an Enum.KeyCode.
CallbackfunctionnilCalled with (Enum.KeyCode) every time the bound key is pressed (not on reassign).
lua
1Section:AddKeybind({
2 Name = "Toggle ESP",
3 Default = Enum.KeyCode.F,
4 Flag = "ESPKey",
5 Callback = function(key)
6 print("key pressed:", key)
7 end
8})
Note: The callback fires on every keypress, not just when reassigning. It does not fire while the input box is in listening mode.
AddColorPicker
A compact HSV color picker. Click the preview swatch to open the picker panel. Supports saturation/value field drag, hue bar drag, and direct hex input.
KeyTypeDefaultDescription

DefaultColor3Color3.new(1,1,1)Initial colour. Parsed into HSV on creation.
FlagstringnilKey in Cactus.Flags. Stores a Color3.
CallbackfunctionnilCalled with (Color3) continuously while dragging.

Methods

MethodDescription
:Set(Color3)Update the colour programmatically. Repaints the picker.

6 -- c is a Color3 — apply to your drawing objects

Cactus.Notify
Sends a toast notification to the bottom-right corner. Stacks cleanly. Auto-dismisses after Duration seconds with a depleting progress bar.
KeyTypeDefaultDescription
Titlestring"Cactus"Bold heading of the notification.
Descriptionstring""Optional body text below the title. Wraps to multiple lines.
Durationnumber4Seconds before the notification slides out.
Typestring"Info"Controls the accent strip colour. One of: "Info" "Success" "Warning" "Error".
lua
1Cactus.Notify({
2 Title = "Script loaded",
3 Description = "v2.1 — all modules ready",
4 Duration = 5,
5 Type = "Success"
6})
7
8Cactus.Notify({ Title = "Detected", Type = "Error", Duration = 8 })
9Cactus.Notify({ Title = "Low FOV", Type = "Warning" })
Global keybinds
These are always active regardless of which tab is open.
KeyAction
RightShiftToggle the window open/closed. Fires Window:Open() or Window:Close().
Minimize buttonCollapses the window to its header bar only. Click the yellow dot.
Close buttonCloses the window (same as Window:Close()). Red dot in header.
Header dragClick and drag the header bar to reposition the window anywhere on screen.
Custom toggle key: Override the default by connecting UserInputService.InputBegan yourself and calling Window:Close() / Window:Open() on your chosen key.
Full example
A realistic script using most of the library's features in one go.
lua — full script
1local Cactus = loadstring(game:HttpGet("https://raming6.github.io/cacuilib/Cactus.lua"))()
2
3local W = Cactus.CreateWindow({ Title = "Cactus", Subtitle = "v1.0" })
4
5-- Tabs
6local Combat = W:AddTab({ Name = "Combat" })
7local Visuals = W:AddTab({ Name = "Visuals" })
8local Settings = W:AddTab({ Name = "Settings" })
9
10-- SubTabs on Combat
11local AimSub = Combat:AddSubTab("Aimbot")
12local TrigSub = Combat:AddSubTab("Trigger")
13
14local AimSec = AimSub:AddSection({ Name = "Aimbot" })
15AimSec:AddToggle({ Name="Enabled", Flag="AimbotOn" })
16AimSec:AddSlider({ Name="FOV", Min=5, Max=360, Default=90, Flag="AimbotFOV", Suffix="°" })
17AimSec:AddDropdown({ Name="Bone", Items={"Head","Neck","Torso"}, Default="Head", Flag="AimBone" })
18AimSec:AddKeybind({ Name="Hold Key", Default=Enum.KeyCode.Q, Flag="AimKey" })
19
20-- Visuals section
21local VisSec = Visuals:AddSection({ Name = "ESP" })
22VisSec:AddToggle({ Name="Boxes", Flag="ESPBoxes" })
23VisSec:AddToggle({ Name="Tracers", Flag="ESPTracers" })
24VisSec:AddColorPicker({ Name="Box Color", Flag="ESPColor" })
25
26-- read flags anywhere
27game:GetService("RunService").Heartbeat:Connect(function()
28 if Cactus.Flags.AimbotOn then
29 -- run aimbot with Cactus.Flags.AimbotFOV and Cactus.Flags.AimBone
30 end
31end)
32
33Cactus.Notify({ Title="Loaded", Type="Success", Duration=3 })
